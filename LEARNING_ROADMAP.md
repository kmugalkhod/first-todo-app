# Todoist-Style App Learning Roadmap

We will build a small Todoist-style app gradually. Every piece of code will be explained before we move on, so you can understand it line by line.

## What We Will Build

### 1. Tasks

- Add a task
- View tasks
- Mark a task as complete
- Delete a task

### 2. Better Task Details

- Add due dates
- Set task priorities
- Organize tasks into projects such as Personal and Work
- Filter tasks by Today, Upcoming, and Completed

### 3. Persistence

- Save tasks in a database so they are not lost when the page refreshes

### 4. Authentication

- Sign up and sign in
- Let each person see only their own tasks

### 5. Real App Polish

- Edit tasks
- Build a responsive sidebar
- Add dark mode
- Drag and reorder tasks
- Deploy the app

## Our First Milestone

Build a page that displays a task list and lets you add, complete, and delete tasks.

At first, tasks will exist only in the browser. This lets us focus on learning React and Next.js fundamentals before introducing a database.

## What You Will Learn Along the Way

- Next.js pages, layouts, and routing
- React components, props, and state
- TypeScript basics
- Forms and event handlers
- Styling with CSS and Tailwind CSS
- Server-side code and databases later in the project

We will keep every step small. First, we will inspect the existing project structure and then build the basic task-list interface.
