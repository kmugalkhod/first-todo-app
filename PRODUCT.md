# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The primary user is the product owner, using the app to manage personal tasks.

## Product Purpose

This is a production-oriented task-management application. It is intended to help its user capture, view, complete, and delete tasks, with the initial milestone focused on a usable task list.

## Positioning

An intentionally small task app being developed from first principles, with the product owner as its first real user and accessibility as a non-negotiable requirement.

## Operating Context

Tasks are managed in a web interface. Planned task organization includes projects, due dates, priorities, and views for all tasks, inbox, upcoming, and completed work.

## Capabilities and Constraints

- The current app is a Next.js web application.
- The initial product scope is adding, viewing, completing, and deleting tasks.
- Persistence, authentication, editing, drag-and-drop reordering, and production data/privacy requirements are not yet decided.
- The application is intended for production use; its exact launch scope and task workflow remain open.

## Evidence on Hand

- The repository contains a Todoist-style learning roadmap at `LEARNING_ROADMAP.md`.
- The current interface includes a task-app sidebar and navigation for all tasks, inbox, completed tasks, and settings.
- No validated user research, customer proof, production data model, or brand assets are present in the repository.

## Product Principles

- Make the core task loop clear and dependable before expanding the feature set.
- Treat the product owner as the first real user while keeping the experience suitable for production use.
- Build progressive task-management capabilities without compromising the core workflow.
- Make accessibility a requirement of every product decision, not a later enhancement.

## Accessibility & Inclusion

Accessibility is an explicit product requirement. The target conformance standard and any specific assistive-technology or localization requirements remain undecided.
